# Khalij-Hengam-Ammonia-Urea-Corrosion-Biuret-Digital-Twin-System (Khalij-HAUC)

## سامانه هوشمند پیش‌بینی ریسک ترک‌خوردگی تنشی-خوردگی (SCC) راکتور اوره، حسگر مجازی بیورت و بهینه‌سازی دوقطبی دما/زمان ماند برای کمینه‌سازی هم‌زمان ریسک خوردگی و بیورت — محصول اختصاصی شرکت پتروشیمی هنگام

> این سند یک محصول **اختصاصی** برای شرکت پتروشیمی هنگام (فاز ۲، عسلویه) است — نخستین مجتمع آمونیاک-اوره در فهرست این پروژه. زنجیره فرایندی آمونیاک-اوره (سنتز آمونیاک با کاتالیست آهن + سنتز اوره با محیط شدیداً خورنده کاربامات) کاملاً متفاوت از سایر شرکت‌های پتروشیمی الفین/آروماتیک هلدینگ است.

## ۰. شناخت شرکت پتروشیمی هنگام و شکاف فنی

**منابع:** [PGPIC — پتروشیمی هنگام](https://pgpic.ir/%D8%B4%D8%B1%DA%A9%D8%AA-%D9%87%D8%A7%DB%8C-%D8%AA%D8%A7%D8%A8%D8%B9%D9%87/%D8%B7%D8%B1%D8%AD-%D9%87%D8%A7%DB%8C-%D8%AF%D8%B1-%D8%AD%D8%A7%D9%84-%D8%A7%D8%AC%D8%B1%D8%A7/%D8%B4%D8%B1%DA%A9%D8%AA-%D9%BE%D8%AA%D8%B1%D9%88%D8%B4%DB%8C%D9%85%DB%8C-%D9%87%D9%86%DA%AF%D8%A7%D9%85)

### محصولات و ماهیت فرایند

| ویژگی | مقدار |
|---|---|
| آمونیاک | ۷۲۶,۰۰۰ تن/سال (لیسانس Haldor Topsoe) |
| اوره | ۱,۱۵۵,۰۰۰ تن/سال (لیسانس Saipem/Snamprojetti — فرایند استریپینگ CO₂) |
| محل | منطقه ویژه اقتصادی انرژی پارس، فاز ۲، عسلویه — ۲۵٫۴۷ هکتار |
| سرمایه‌گذاری | ۸۰۰ میلیون یورو |

**فیزیک فرایندی حیاتی:** راکتور سنتز اوره در دمای بالا (~۱۸۰-۲۱۰ درجه سانتی‌گراد) و فشار بسیار بالا (~۱۴۰-۲۵۰ بار) با محیط **کاربامات آمونیوم** کار می‌کند که یکی از خورنده‌ترین محیط‌های صنعتی برای فولاد زنگ‌نزن آستنیتی است و از دهه ۱۹۷۰ به‌عنوان منبع حوادث ترک‌خوردگی تنشی-خوردگی (SCC) شناخته‌شده است. در همان زمان، دمای بالاتر برای کاهش محتوای **بیورت** (ناخالصی سمی برای برخی گیاهان، باید زیر ~۱٪ بماند) لازم است — یعنی **کاهش بیورت و افزایش ریسک خوردگی معمولاً هم‌جهت هستند**، یک مصالحه فیزیکی واقعی.

### شکاف فنی نسبت به محصولات ۱ تا ۴ هلدینگ

| محصول هلدینگ | چرا برای هنگام کافی نیست |
|---|---|
| همه محصولات ۱-۴ و محصولات اختصاصی قبلی | هیچ‌کدام زنجیره آمونیاک-اوره، محیط کاربامات خورنده، یا کیفیت بیورت را پوشش نمی‌دهند؛ این نخستین محصول هلدینگ در حوزه کود شیمیایی است |

**نتیجه:** هنگام نیاز به دوقلوی دیجیتال اختصاصی دارد که مصالحه فیزیکی بین ریسک خوردگی و کیفیت بیورت را به‌صورت کمی مدل کند.

## ۲. سند SRS – محصول اختصاصی پتروشیمی هنگام

### ۲-۱. مقدمه
**هدف:** افزایش ایمنی راکتور اوره از طریق پیش‌بینی ریسک SCC، و تضمین کیفیت محصول (بیورت زیر آستانه) با مدیریت هوشمند مصالحه دما/کیفیت/خوردگی.

**چالش‌های میدانی:**
- ریسک SCC راکتور اوره معمولاً با بازرسی دوره‌ای (نه پایش پیوسته) مدیریت می‌شود.
- کاهش بیورت نیازمند دمای بالاتر است که ریسک خوردگی را افزایش می‌دهد — تصمیم عملیاتی معمولاً محافظه‌کارانه و غیربهینه گرفته می‌شود.
- فعالیت کاتالیست آهنی سنتز آمونیاک با گذر زمان افت می‌کند و بر نسبت N₂:H₂ ورودی به اوره اثر می‌گذارد.

**دامنه:** مجتمع هنگام، عسلویه؛ اتصال به DCS واحدهای سنتز آمونیاک و اوره.

## ۳. کد تولید داده‌های سنتتیک

```python
import numpy as np
import pandas as pd
from datetime import datetime, timedelta

NUM_RECORDS = 10000
START_TIME = datetime(2026, 9, 14, 8, 0, 0)
timestamps = [START_TIME + timedelta(minutes=i) for i in range(NUM_RECORDS)]
t = np.linspace(0, 20 * np.pi, NUM_RECORDS)

# ۱. راکتور اوره
reactor_temp_c = 190 + 6 * np.sin(t * 0.08) + np.random.normal(0, 1, NUM_RECORDS)
reactor_pressure_bar = 150 + 5 * np.sin(t * 0.08 + 0.2) + np.random.normal(0, 1.5, NUM_RECORDS)
carbamate_concentration_percent = 38 + 2 * np.sin(t * 0.06) + np.random.normal(0, 0.5, NUM_RECORDS)

# ۲. ریسک SCC (تابع دما، فشار و غلظت کاربامات)
scc_risk_index = 0.02 * (reactor_temp_c - 190) + 0.015 * (reactor_pressure_bar - 150) + 0.01 * (carbamate_concentration_percent - 38) + np.random.normal(0, 0.05, NUM_RECORDS)
scc_risk_index = np.clip(scc_risk_index, 0, 5)

# ۳. کیفیت بیورت (کاهش با افزایش دما)
biuret_content_percent = 1.3 - 0.015 * (reactor_temp_c - 190) + np.random.normal(0, 0.05, NUM_RECORDS)
biuret_content_percent = np.clip(biuret_content_percent, 0.3, 2.0)

# ۴. کاتالیست آمونیاک
ammonia_catalyst_activity_percent = 100 - 0.0005 * np.arange(NUM_RECORDS) + np.random.normal(0, 0.3, NUM_RECORDS)
n2_h2_ratio = 0.33 + 0.02 * np.sin(t * 0.1) + np.random.normal(0, 0.005, NUM_RECORDS)

# ۵. برچسب‌ها
scc_critical_alert = (scc_risk_index > 3.5).astype(int)
biuret_off_spec = (biuret_content_percent > 1.0).astype(int)

df = pd.DataFrame({
    'timestamp': timestamps,
    'reactor_temp_c': np.round(reactor_temp_c, 2),
    'reactor_pressure_bar': np.round(reactor_pressure_bar, 2),
    'carbamate_concentration_percent': np.round(carbamate_concentration_percent, 2),
    'scc_risk_index': np.round(scc_risk_index, 3),
    'biuret_content_percent': np.round(biuret_content_percent, 3),
    'ammonia_catalyst_activity_percent': np.round(ammonia_catalyst_activity_percent, 2),
    'n2_h2_ratio': np.round(n2_h2_ratio, 4),
    'scc_critical_alert': scc_critical_alert,
    'biuret_off_spec': biuret_off_spec,
})

df.to_csv("hengam_ammonia_urea_data_10k.csv", index=False)
print(f"✅ ذخیره شد. رکوردها: {len(df):,} - متغیرها: {len(df.columns)}")
print(df.describe())
```
