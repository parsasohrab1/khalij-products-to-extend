# Khalij-Howeizeh-Amine-Claus-SourGas-Digital-Twin-System (Khalij-HACS)

## سامانه هوشمند پیش‌بینی زوال/کف‌کردگی آمین از ترکیب گاز ترش چهارمنبعی و بهینه‌سازی زنجیره‌ای بلادرنگ واحد بازیابی گوگرد کلاوس — محصول اختصاصی شرکت پالایش گاز هویزه خلیج فارس

> این سند یک محصول **اختصاصی** برای شرکت پالایش گاز هویزه خلیج فارس است — پالایشگاه شیرین‌سازی گاز ترش همراه از چهار میدان نفتی (یادآوران، یاران، آزادگان، دارخوین) با ظرفیت نهایی ۵۰۰ میلیون فوت مکعب/روز. این محصول با محصول اختصاصی بیدبلند (استخراج NGL کرایوژنیک) همپوشانی ندارد؛ زیرا شیمی هویزه (شیرین‌سازی آمینی + بازیابی گوگرد کلاوس روی گاز شدیداً ترش) کاملاً متفاوت است.

## ۰. شناخت شرکت پالایش گاز هویزه خلیج فارس و شکاف فنی

**منابع:** [ویکی‌پدیا فارسی — پالایشگاه گاز هویزه خلیج‌فارس](https://fa.wikipedia.org/wiki/%D9%BE%D8%A7%D9%84%D8%A7%DB%8C%D8%B4%DA%AF%D8%A7%D9%87_%DA%AF%D8%A7%D8%B2_%DB%8C%D8%A7%D8%AF%D8%A2%D9%88%D8%B1%D8%A7%D9%86_%D8%AE%D9%84%DB%8C%D8%AC%E2%80%8C%D9%81%D8%A7%D8%B1%D8%B3)

### محصولات و ماهیت فرایند

| ویژگی | مقدار |
|---|---|
| محل | منطقه جفیر، هویزه، خوزستان |
| خوراک | گاز ترش همراه نفت از میادین یادآوران، یاران، آزادگان، دارخوین (میادین غرب کارون — شناخته‌شده برای گاز بسیار ترش/خورنده) |
| ظرفیت نهایی (فاز ۲) | ۵۰۰ میلیون فوت مکعب/روز |
| ظرفیت فاز ۱ | ۲۵۰ میلیون فوت مکعب/روز |
| مقصد محصول | ۲۵۰ میلیون فوت مکعب/روز به شبکه سراسری گاز، ۹۰ میلیون فوت مکعب/روز سوخت نیروگاه سیکل‌ترکیبی غرب کارون |

**فرایند فنی:** گاز ترش چهار میدان مختلف (با نسبت H₂S/CO₂ متفاوت و متغیر) وارد **واحد شیرین‌سازی آمینی** (معمولاً MDEA) می‌شود که H₂S/CO₂ را جذب می‌کند؛ گاز اسیدی غنی از H₂S سپس به **واحد بازیابی گوگرد کلاوس (SRU)** می‌رود. دو ریسک کلیدی: (الف) زوال/کف‌کردگی حلال آمین ناشی از آلاینده‌های متغیر خوراک، و (ب) افت بازده SRU در صورت نوسان ناگهانی غلظت H₂S گاز اسیدی ورودی (که خود ناشی از تغییر خوراک/عملکرد آمین است).

### شکاف فنی نسبت به سایر محصولات هلدینگ

| محصول | چرا برای هویزه کافی نیست |
|---|---|
| محصول اختصاصی بیدبلند | شیمی کاملاً متفاوت (کرایوژنیک/NGL در برابر شیرین‌سازی آمینی/کلاوس)؛ بیدبلند به هیدرات و بازیابی اتان می‌پردازد، نه زوال آمین یا بازده گوگرد |
| هیچ محصول هلدینگ | به زنجیره **آمین → گاز اسیدی → کلاوس** که نوسان یک واحد مستقیماً بازده واحد بعدی را متأثر می‌کند، نپرداخته |

**نتیجه:** هویزه نیاز به دوقلوی دیجیتال زنجیره‌ای اختصاصی آمین-کلاوس دارد که ترکیب متغیر خوراک چهارمنبعی را ببیند.

## ۲. سند SRS – محصول اختصاصی پالایش گاز هویزه خلیج فارس

### ۲-۱. مقدمه
**هدف:** افزایش پایداری و عمر حلال آمین، و حفظ بازده بازیابی گوگرد کلاوس در برابر نوسان ترکیب خوراک چهارمنبعی.

**چالش‌های میدانی:**
- ترکیب متغیر گاز ترش از چهار میدان مختلف (با نسبت H₂S/CO₂/آلاینده متفاوت) باعث نوسان پیش‌بینی‌نشده در عملکرد آمین می‌شود.
- افت راندمان جذب آمین یا کف‌کردگی مستقیماً غلظت/دبی H₂S ورودی به کلاوس را تغییر می‌دهد و بازده بازیابی گوگرد را کاهش می‌دهد (ریسک محیط‌زیستی و انطباق با استاندارد انتشار).
- نبود ابزاری که این دو واحد را به‌صورت زنجیره‌ای ببیند.

**دامنه:** مجتمع هویزه؛ اتصال به DCS واحدهای شیرین‌سازی آمینی و کلاوس.

## ۳. کد تولید داده‌های سنتتیک

```python
import numpy as np
import pandas as pd
from datetime import datetime, timedelta

NUM_RECORDS = 10000
START_TIME = datetime(2026, 9, 14, 8, 0, 0)
timestamps = [START_TIME + timedelta(minutes=i) for i in range(NUM_RECORDS)]

fields = ["Yadavaran", "Yaran", "Azadegan", "Darkhovin"]
field_shift = np.random.choice(range(4), size=NUM_RECORDS // 250 + 1)
current_field_idx = np.repeat(field_shift, 250)[:NUM_RECORDS]

base_h2s = np.array([3.2, 2.5, 4.0, 2.0])[current_field_idx]  # درصد مولی H2S
base_co2 = np.array([1.8, 2.2, 1.5, 2.5])[current_field_idx]

feed_h2s_percent = base_h2s + np.random.normal(0, 0.15, NUM_RECORDS)
feed_co2_percent = base_co2 + np.random.normal(0, 0.1, NUM_RECORDS)

# واحد آمین
amine_loading_mol_ratio = 0.45 + 0.02 * feed_h2s_percent + np.random.normal(0, 0.02, NUM_RECORDS)
foaming_index = 0.5 + 0.3 * (feed_h2s_percent - 3) + np.random.normal(0, 0.2, NUM_RECORDS)
foaming_index = np.clip(foaming_index, 0, 5)

# گاز اسیدی به کلاوس
acid_gas_h2s_percent = 88 - 2 * foaming_index + np.random.normal(0, 1.5, NUM_RECORDS)
acid_gas_flow_nm3h = 4200 + 150 * (feed_h2s_percent - 3) + np.random.normal(0, 80, NUM_RECORDS)

# واحد کلاوس
air_feed_ratio = 2.05 + 0.01 * (acid_gas_h2s_percent - 88) + np.random.normal(0, 0.02, NUM_RECORDS)
sulfur_recovery_efficiency_percent = 98.5 - 0.5 * np.abs(air_feed_ratio - 2.05) * 10 - 0.3 * foaming_index + np.random.normal(0, 0.3, NUM_RECORDS)
sulfur_recovery_efficiency_percent = np.clip(sulfur_recovery_efficiency_percent, 90, 99.5)

# برچسب‌ها
foaming_critical_alert = (foaming_index > 3).astype(int)
sru_efficiency_risk = (sulfur_recovery_efficiency_percent < 96).astype(int)

df = pd.DataFrame({
    'timestamp': timestamps,
    'current_field': [fields[i] for i in current_field_idx],
    'feed_h2s_percent': np.round(feed_h2s_percent, 3),
    'feed_co2_percent': np.round(feed_co2_percent, 3),
    'amine_loading_mol_ratio': np.round(amine_loading_mol_ratio, 3),
    'foaming_index': np.round(foaming_index, 3),
    'acid_gas_h2s_percent': np.round(acid_gas_h2s_percent, 2),
    'acid_gas_flow_nm3h': np.round(acid_gas_flow_nm3h, 1),
    'air_feed_ratio': np.round(air_feed_ratio, 3),
    'sulfur_recovery_efficiency_percent': np.round(sulfur_recovery_efficiency_percent, 2),
    'foaming_critical_alert': foaming_critical_alert,
    'sru_efficiency_risk': sru_efficiency_risk,
})

df.to_csv("howeizeh_amine_claus_data_10k.csv", index=False)
print(f"✅ ذخیره شد. رکوردها: {len(df):,} - متغیرها: {len(df.columns)}")
print(df.describe())
```
