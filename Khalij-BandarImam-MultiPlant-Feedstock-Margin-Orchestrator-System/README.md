# Khalij-BandarImam-MultiPlant-Feedstock-Margin-Orchestrator-System (Khalij-BIMO)

## سامانه هوشمند تخصیص بلادرنگ خوراک، بازآرایی جریان‌های میانی و بهینه‌سازی سود ناخالص هم‌زمان میان ۴ شرکت زیرمجموعه مجتمع پتروشیمی بندرامام — محصول اختصاصی BIPC

> این سند یک محصول **اختصاصی** برای شرکت پتروشیمی بندرامام (BIPC) است. توجه: محصول عمومی ۱ هلدینگ (بهینه‌سازی پارامترهای فرایندی یک راکتور) قبلاً به این شرکت تخصیص یافته بود، اما آن محصول فقط سطح «یک راکتور» را می‌بیند. محصول حاضر، شکاف واقعی و منحصربه‌فرد BIPC — هماهنگی **بین چهار شرکت زیرمجموعه مستقل** با خوراک و یوتیلیتی مشترک — را پوشش می‌دهد و مکمل (نه رقیب) محصول ۱ است.

## ۰. شناخت شرکت پتروشیمی بندرامام (مبتنی بر مطالعه سایت رسمی/PGPIC) و شکاف فنی

**منابع:** [PGPIC — صفحه شرکت بندرامام](https://pgpic.ir/%D8%B4%D8%B1%DA%A9%D8%AA-%D9%87%D8%A7%DB%8C-%D8%AA%D8%A7%D8%A8%D8%B9%D9%87/%D9%85%D8%AC%D8%AA%D9%85%D8%B9-%D9%87%D8%A7%DB%8C-%D8%AA%D9%88%D9%84%DB%8C%D8%AF%DB%8C/%D8%B4%D8%B1%DA%A9%D8%AA-%D9%BE%D8%AA%D8%B1%D9%88%D8%B4%DB%8C%D9%85%DB%8C-%D8%A8%D9%86%D8%AF%D8%B1-%D8%A7%D9%85%D8%A7%D9%85)، [BIPC Products](https://bipc.ir/en/products/)، [ویکی‌پدیا فارسی](https://fa.wikipedia.org/wiki/%D8%B4%D8%B1%DA%A9%D8%AA_%D9%BE%D8%AA%D8%B1%D9%88%D8%B4%DB%8C%D9%85%DB%8C_%D8%A8%D9%86%D8%AF%D8%B1_%D8%A7%D9%85%D8%A7%D9%85)

### ساختار منحصربه‌فرد BIPC (نکته کلیدی برای طراحی محصول)

بندرامام **بزرگ‌ترین مجتمع پتروشیمی ایران** (ظرفیت اسمی ۴٬۷۴۸ کیلوتن/سال، ۲۷۰ هکتار) است و برخلاف اکثر شرکت‌های هلدینگ، از **چهار شرکت زیرمجموعهٔ مجزا** با محصولات و یوتیلیتی به‌هم‌وابسته تشکیل شده:

| زیرمجموعه | واحدها | محصولات |
|---|---|---|
| فرآورش بندرامام | NF (نفتا)، OL (اولفین/کراکر بخار Lummus)، AR (آروماتیک)، PX (پارازایلین) | اتیلن (۴۱۱ کیلوتن)، پروپیلن، بوتان، بنزن/تولوئن/زایلین |
| بسپاران بندرامام | HDPE، LDPE، PP، BD/SR | پلی‌اتیلن سبک/سنگین، پلی‌پروپیلن، بوتادین/لاستیک مصنوعی |
| کیمیا بندرامام | CA (کلرآلکالی)، DC (EDC)، VCM، PVC، MTBE | کاستیک، PVC، MTBE |
| آب‌نیرو بندرامام | برق، بخار، آب، هوا، ازت | یوتیلیتی مشترک کل مجتمع |

### شکاف فنی نسبت به محصولات ۱ تا ۴ هلدینگ

| محصول هلدینگ | چرا برای BIPC کافی نیست |
|---|---|
| محصول ۱ (بهینه‌سازی پارامتر فرایندی) | سطح آن **یک راکتور/یک واحد** است (مثلاً فقط کراکر OL)؛ به تصمیم «کدام خوراک به کدام زیرمجموعه با چه اولویتی برود» یا به وابستگی یوتیلیتی بین ۴ شرکت وارد نمی‌شود |
| محصول ۳ (انرژی/کربن) | برای واحد PTA تک‌محصولی طراحی و به شهید تندگویان تخصیص یافته؛ حالت «یوتیلیتی مشترک بین ۴ شرکت مستقل حقوقی» را پوشش نمی‌دهد |
| محصول ۴ (پایش دارایی) | به شرکت مارون تخصیص یافته و سطح تجهیز/کوره را می‌بیند، نه سطح تخصیص خوراک/سود بین شرکت‌ها |

**نتیجه:** BIPC به یک لایه «ارکستراسیون سطح مجتمع» نیاز دارد که فراتر از یک واحد یا یک شرکت زیرمجموعه، **هم‌زمان چهار شرکت را با محدودیت‌های خوراک، یوتیلیتی مشترک و بازار می‌بیند** — دقیقاً همان چیزی که در هیچ محصول ۱ تا ۴ پوشش داده نشده.

## ۲. سند SRS – محصول اختصاصی پتروشیمی بندرامام

### ۲-۱. مقدمه
**هدف:** حداکثرسازی سود ناخالص کل مجتمع بندرامام از طریق تخصیص بلادرنگ خوراک و ظرفیت یوتیلیتی مشترک بین چهار شرکت زیرمجموعه، و بازتوزیع خودکار جریان‌های میانی هنگام قطعی/نوسان تولید هر واحد.

**چالش‌های میدانی:**
- تصمیم «چه مقدار نفتا/NGL/متانول به کدام واحد (NF→OL→AR/PX) برود» معمولاً بر مبنای برنامه ثابت ماهانه گرفته می‌شود، نه بر مبنای نوسان لحظه‌ای قیمت محصولات نهایی.
- وقتی کراکر OL دچار افت ظرفیت می‌شود، تخصیص اتیلن/پروپیلن بین بسپاران (HDPE/LDPE/PP) و کیمیا (VCM/PVC) معمولاً دستی و با تأخیر انجام می‌شود.
- ظرفیت بخار/برق/ازت آب‌نیرو محدودیت پنهانی است که در برنامه‌ریزی خوراک هر ۳ شرکت دیگر اغلب دیرهنگام لحاظ می‌شود.
- نبود مدل شفاف نرخ انتقال داخلی مبتنی بر داده واقعی برای تصمیم‌گیری منصفانه بین ۴ شرکت.

**دامنه:** مجتمع بندرامام، منطقه ویژه اقتصادی پتروشیمی ماهشهر؛ اتصال به DCS چهار زیرمجموعه و سامانه مالی تسویه بین‌شرکتی.

## ۳. کد تولید داده‌های سنتتیک

```python
import numpy as np
import pandas as pd
from datetime import datetime, timedelta

NUM_RECORDS = 10000
START_TIME = datetime(2026, 9, 14, 8, 0, 0)
timestamps = [START_TIME + timedelta(hours=i/60) for i in range(NUM_RECORDS)]
t = np.linspace(0, 20 * np.pi, NUM_RECORDS)

# ظرفیت لحظه‌ای کراکر (OL) - درصد ظرفیت اسمی
cracker_capacity_percent = 92 + 5 * np.sin(t * 0.08) + np.random.normal(0, 2, NUM_RECORDS)
cracker_capacity_percent = np.clip(cracker_capacity_percent, 60, 100)

# قیمت لحظه‌ای محصولات (دلار بر تن، شبیه‌سازی نوسان بازار)
price_ethylene_usd_ton = 950 + 60 * np.sin(t * 0.03) + np.random.normal(0, 15, NUM_RECORDS)
price_hdpe_usd_ton = 1150 + 80 * np.sin(t * 0.025 + 1) + np.random.normal(0, 20, NUM_RECORDS)
price_pvc_usd_ton = 900 + 50 * np.sin(t * 0.02 + 2) + np.random.normal(0, 18, NUM_RECORDS)

# ظرفیت یوتیلیتی مشترک آب‌نیرو (٪ ظرفیت در دسترس بخار/برق)
utility_steam_available_percent = 88 + 6 * np.sin(t * 0.05) + np.random.normal(0, 3, NUM_RECORDS)
utility_power_available_percent = 90 + 4 * np.sin(t * 0.06 + 0.5) + np.random.normal(0, 2, NUM_RECORDS)

# تخصیص خوراک بین واحدها (شبیه‌سازی سهم بهینه فعلی)
naphtha_to_ol_percent = 70 + 10 * np.sin(t * 0.04) + np.random.normal(0, 3, NUM_RECORDS)
naphtha_to_ol_percent = np.clip(naphtha_to_ol_percent, 40, 90)

# سود ناخالص لحظه‌ای برآوردی کل مجتمع (میلیون دلار/روز، شبیه‌سازی)
estimated_gross_margin_musd_day = (
    0.02 * cracker_capacity_percent
    + 0.015 * (price_ethylene_usd_ton - 900)
    + 0.01 * (price_hdpe_usd_ton - 1100)
    + 0.008 * (price_pvc_usd_ton - 880)
    - 0.01 * (100 - utility_steam_available_percent)
    + np.random.normal(0, 0.3, NUM_RECORDS)
)

# برچسب: نیاز به بازآرایی فوری جریان میانی (وقتی ظرفیت کراکر یا یوتیلیتی افت شدید کند)
needs_reallocation = ((cracker_capacity_percent < 75) | (utility_steam_available_percent < 75)).astype(int)

df = pd.DataFrame({
    'timestamp': timestamps,
    'cracker_capacity_percent': np.round(cracker_capacity_percent, 2),
    'price_ethylene_usd_ton': np.round(price_ethylene_usd_ton, 1),
    'price_hdpe_usd_ton': np.round(price_hdpe_usd_ton, 1),
    'price_pvc_usd_ton': np.round(price_pvc_usd_ton, 1),
    'utility_steam_available_percent': np.round(utility_steam_available_percent, 2),
    'utility_power_available_percent': np.round(utility_power_available_percent, 2),
    'naphtha_to_ol_percent': np.round(naphtha_to_ol_percent, 2),
    'estimated_gross_margin_musd_day': np.round(estimated_gross_margin_musd_day, 3),
    'needs_reallocation': needs_reallocation,
})

df.to_csv("bipc_multiplant_margin_data_10k.csv", index=False)
print(f"✅ ذخیره شد. رکوردها: {len(df):,} - متغیرها: {len(df.columns)}")
print(df.describe())
```

**Payback:** با توجه به مقیاس بزرگ‌ترین مجتمع پتروشیمی ایران (۴٬۷۴۸ کیلوتن/سال)، حتی بهبود ۰.۵-۱٪ در سود ناخالص کل مجتمع از طریق تخصیص بهینه خوراک، ارزش اقتصادی چندمیلیون‌دلاری سالانه دارد که هزینه پیاده‌سازی را به‌سرعت جبران می‌کند.

## ۶. جمع‌بندی نوآوری‌های قابل ثبت اختراع

1. **بهینه‌سازی چندشرکتی خوراک و جریان میانی** بین ۴ شرکت زیرمجموعه مستقل حقوقی یک مجتمع، با نرخ انتقال داخلی.
2. **پیوند مستقیم قید ظرفیت یوتیلیتی مشترک** (بخار/برق/ازت) به تصمیم تخصیص خوراک سایر شرکت‌ها در یک مدل واحد.
3. **بازآرایی خودکار بلادرنگ جریان‌های میانی** بین شرکت‌ها هنگام قطعی/نوسان با محاسبه اثر مالی سناریو.
